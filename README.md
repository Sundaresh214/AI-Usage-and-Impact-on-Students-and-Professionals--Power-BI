# AI Usage and Impact on Students and Professionals

An interactive Power BI project exploring AI usage patterns and perceived impact among students and professionals.

## Project Overview
This report is designed to explore how students and professionals use artificial intelligence and compare patterns in their reported experiences. Validate specific metrics and conclusions against the Power BI report and its source data before publishing them.

## Objectives
- Explore AI usage among students and professionals.
- Compare patterns between the two groups.
- Examine reported use cases, benefits, challenges, and perceived impact where the data supports them.
- Present findings through interactive Power BI visuals.

## Tools
- Microsoft Power BI
- Power Query (where used)
- DAX (where used)
- Data visualization

## How to Open
1. Download or clone this repository.
2. Install Microsoft Power BI Desktop.
3. Open the `.pbix` file.
4. If prompted, reconnect or refresh the data source and verify that the report loads correctly.
5. Explore the report pages, filters, and slicers.

## Analysis Areas
Depending on the fields available in the report, explore AI adoption, usage frequency, tools and use cases, student-versus-professional comparisons, and reported benefits or challenges.

## Value
This project demonstrates interactive reporting and exploratory analysis of AI usage. It can support discussion about how AI is adopted in educational and professional settings.
